# Higgs voice bridge

Voice calls: this repo's `bridge.py` runs a Higgs Realtime voice that hands tasks to whichever coding agent is watching
`~/.higgs/inbox.jsonl`. To be that agent (Codex, Claude Code, anything with a shell), follow `.agents/skills/call/SKILL.md`.
Boson API questions: read `docs/INDEX.md`, then grep `docs/`; do not fetch the web.
