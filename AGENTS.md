# Higgs voice bridge

Voice calls: this repo's `bridge.py` runs a Higgs Realtime voice, "Donna", whose tasks land in
`~/.higgs/herd/donna/inbox.jsonl` (the herd, `herd.py`). To be Donna's brain (Codex, Claude Code, anything with a
shell), follow `.agents/skills/call/SKILL.md`.
Boson API questions: read `docs/INDEX.md`, then grep `docs/`; do not fetch the web.
