# Languages

> Higgs TTS 3 supports 102 languages with single-digit WER/CER.

Language is auto-detected from the input text, so you do not need to specify it in the API. For cloned voices, match the language of the input text and reference audio when possible. To generate speech with a particular accent, such as British English, use a reference clip with that accent.

## Supported languages

Coverage is measured by word or character error rate (WER/CER) — **lower is better**. Languages are grouped by quality tier and ordered alphabetically within each tier.
