# LiveKit

> LiveKit support status for Higgs Realtime, and what to use in the meantime.

A first-party LiveKit integration for Higgs Realtime is coming soon. In the meantime, connect to the Realtime API directly over [WebSocket](https://docs.boson.ai/models/higgs-realtime/guides/connections-and-sessions.md), or use the [Pipecat integration](https://docs.boson.ai/models/higgs-realtime/integrations/pipecat.md).
